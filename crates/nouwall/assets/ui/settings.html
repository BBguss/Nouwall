    nouwall

    Live wallpaper open source untuk Windows. Shader, video, dan halaman web berjalan di belakang ikon desktop, dengan peringatan otomatis sesuai kemampuan hardware.

    Lokasi berkas

    Membuat wallpaper

    Setiap wallpaper adalah folder dengan wallpaper.toml

    Shader GLSL

    Konvensi Shadertoy dengan iTime, iResolution, iMouse, iFrame, dan iDate.

    void mainImage(out vec4 fragColor,
               in vec2 fragCoord) {
  vec2 uv = fragCoord / iResolution.xy;
  fragColor = vec4(uv, 0.5 + 0.5 * sin(iTime), 1.0);
}

    Shader WGSL

    Uniform tersedia di u: resolution, time, mouse, frame, date.

    fn main_image(frag_coord: vec2<f32>) -> vec4<f32> {
  let uv = frag_coord / u.resolution.xy;
  return vec4<f32>(uv, 0.5, 1.0);
}

    Halaman web

    Halaman biasa. Saat wallpaper dijeda, halaman menerima event berikut.

    addEventListener('nouwall:pause', stop);
addEventListener('nouwall:resume', start);
