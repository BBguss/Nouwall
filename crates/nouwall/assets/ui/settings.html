    nouwall

    Live wallpaper open source untuk Windows: shader, video, dan halaman web di belakang ikon desktop, dengan peringatan otomatis sesuai kemampuan hardware.

    Membuat wallpaper

    Shader GLSL memakai konvensi Shadertoy: void mainImage(out vec4 fragColor, in vec2 fragCoord) dengan iTime, iResolution, iMouse. Shader WGSL mendefinisikan fn main_image(frag_coord: vec2<f32>) -> vec4<f32>. Halaman web menerima event nouwall:pause dan nouwall:resume.

    Perangkat mungkin tidak mendukung

    Halaman akan dimuat dari internet setiap kali wallpaper dimulai.
